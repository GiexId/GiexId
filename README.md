## 🚀 Proyek Unggulan

# 📡 RTRW-Net Monitor

Sistem monitoring kualitas sinyal jaringan RT RW Net dengan notifikasi otomatis saat terjadi gangguan.

## 🎯 Masalah yang Diselesaikan
Gangguan jaringan sering baru diketahui setelah pelanggan komplain. Proyek ini memantau sinyal secara berkala dan mengirim alert lebih dulu.

## ✨ Fitur
- Pengecekan sinyal/latency perangkat secara berkala
- Alert otomatis ke [Telegram/WhatsApp] saat sinyal di bawah ambang batas
- Otomasi alur kerja dengan n8n
- [Dashboard/log riwayat sinyal]

## 🧱 Arsitektur
```text
[Perangkat/AP] → [Pengambil data] → [n8n] → [Notifikasi]
                                      ↓
                              [Database/Log]

```
